### 2. Hotel Booking Analysis
**Objective**
- Analyse a real-world hotel booking dataset to identify booking trends and cancellation patterns.

**Skills Used**
- Pivot Tables
- Pivot Charts
- COUNTIFS
- AVERAGEIFS
- Power Pivot
- Dashboard Design
- Data Analysis

**Key Insights**
- Overall cancellation rate: **37.04%**
- City Hotels had a higher cancellation rate than Resort Hotels.
- August recorded the highest number of bookings.
- June had the highest cancellation rate.
- Online TA generated the highest number of bookings.
